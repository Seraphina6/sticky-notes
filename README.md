# sticky-notes

事情源于我找了一圈便签 APP，要么广告多要么要会员（之前用的一款免费好用但是总量限制10个），一气之下让 AI 帮我写了一个，结果越用越顺手😭  
分享一下我最爱的几个功能👇  
❶ 四种便签类型 普通文本 / 待办事项 / 提醒便签 / 时间轴，写计划、记待办、定提醒一个工具全搞定，待办还带进度条超有成就感✅  
❷ 全端自适应 手机竖屏单列、平板双列、电脑大屏多列，窗口随便拉都不乱版，通勤用手机回家用电脑无缝切换📱💻  
❸ 分组 + 搜索 学习 / 工作 / 生活随便分组，支持全局搜索标题和内容，几百条便签也能秒找到🔍  
❹ 导入导出 数据一键备份导出，不怕丢，换设备也能迁移📦  
界面默认是蓝色的极简风(看不顺眼可更换为其他颜色)，置顶功能也有，完全是我想要的样子！  
你们平时用什么便签工具？评论区聊聊～
